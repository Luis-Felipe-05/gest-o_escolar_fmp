================================================================================
PARTE 1 — O QUE ESTE SCRIPT FAZ
================================================================================
O site (index.html + app.js) é 100% estático: ele não tem servidor próprio.
Este script É o servidor. Ele fica rodando "na nuvem" do Google e expõe uma URL
(/exec) que o navegador chama para ler e gravar os dados.

Ações que o site usa (já implementadas abaixo):

  GET  .../exec?acao=ping&chave=XXX        → teste de conexão (botão "Testar Conexão")
                                             + informa a URL exata da planilha usada
  GET  .../exec?acao=carregar&chave=XXX    → devolve { dados, versao, script } (estado inteiro)
  POST .../exec  corpo { acao:'salvar', chave, versao, operacoes }     → salva só o que
             mudou: células (nota / conceito / frequência / situação) e
             REMENDOS de estrutura { op:'caminho', caminho:[...], valor }
             ▲
        Isso evita que a nota de um professor sobrescreva a do outro e permite
        que a turma/aluno criado por você seja MESCLADO com o que o colega
        salvou ao mesmo tempo (em vez de virar "conflito").
  POST .../exec  corpo { acao:'salvar', chave, versao, dados, forcar:true }
                                                              → usa só na
        RESTAURAÇÃO DE BACKUP (substitui a planilha inteira, ignorando a versão)

  Toda resposta traz "script": 2. Se o site receber uma resposta SEM esse campo,
  é sinal de que o Apps Script publicado está desatualizado — o app avisa em vez
  de deixar as alterações sumirem em silêncio.

Onde os dados ficam guardados?
  → Numa planilha do Google Sheets chamada "BD - Sistema de Notas (Apps Script)",
    criada AUTOMATICAMENTE na primeira execução. O JSON é guardado fatiado em
    linhas (a planilha tem limite de 50.000 caracteres por célula; usamos 40.000).
    O botão "Testar Conexão" mostra a URL EXATA dessa planilha — se você não
    acha a aba DADOS, confira se está abrindo a planilha certa do Drive.
  → A "versão" (número) também fica na planilha. Ela serve para detectar CONFLITO:
    se duas pessoas salvam ao mesmo tempo, o script devolve { conflito:true,
    versao, dados } e o app carrega a versão nova, reaplica por cima o que você
    digitou (notas E turmas/alunos) e reenvia — tudo automaticamente, sem você
    precisar refazer nada (tudo isso já está no app.js).

Segurança:
  → Toda chamada precisa da CHAVE_SECRETA. Sem a chave, o script responde erro.
  → Ninguém "edita" a planilha pela URL: a URL só executa as 3 ações acima.

Backup semanal (a parte que você pediu):
  → Um DISPARADOR (trigger) de 7 em 7 dias executa a função backupSemanalNoDrive(),
    que baixa o JSON completo dos dados e grava um arquivo
    "backup-notas-AAAA-MM-DD.json" dentro da pasta do Drive
    "Backups - Sistema de Notas (JSON)". Mantém os últimos 12 backups e apaga os
    mais velhos. O formato é EXATAMENTE o que o botão "Restaurar backup (.json)"
    do app entende, ou seja: dá pra restaurar direto do Drive pela aba Admin.

var CHAVE_SECRETA = 'sn_CKmB5M38WP2zbeGTSOgfqcUYLJxakwrA';

var NOME_BANCO        = 'BD - Sistema de Notas (Apps Script)';   // planilha de dados
var NOME_PASTA_BACKUP = 'Backups - Sistema de Notas (JSON)';     // pasta do Drive (backups semanais)
var ABA_DADOS         = 'DADOS';
var TAM_FRAGMENTO     = 40000;   // caracteres por célula (limite do Sheets = 50.000)
var MAX_BACKUPS       = 12;      // quantos arquivos .json manter na pasta (≈ 3 meses)
var HORA_BACKUP       = 6;       // hora (0-23) do backup semanal, fuso do script

// Versão deste backend. É devolvida em todas as respostas; o site (app.js)
// confere esse número e AVISA se o script publicado estiver desatualizado —
// assim nenhuma alteração se perde em silêncio.
var SCRIPT_VERSAO = 2;

var PROP_SS    = 'SPREADSHEET_ID';
var PROP_PASTA = 'PASTA_BACKUP_ID';

// ===================== RESPOSTA PADRÃO (JSON) =====================
function json_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

// Responde ao pré-flight CORS do navegador (o site roda em outro domínio).
// Hoje o app envia Content-Type text/plain, que já dispensa preflight, mas
// deixamos aqui por segurança.
function doOptions() {
  try {
    var out = json_({ ok: true });
    out.addHeader('Access-Control-Allow-Origin', '*');
    out.addHeader('Access-Control-Allow-Methods', 'GET, POST, OPTIONS');
    out.addHeader('Access-Control-Allow-Headers', 'Content-Type');
    return out;
  } catch (e) {
    return ContentService.createTextOutput('').setMimeType(ContentService.MimeType.TEXT);
  }
}

// ===================== LEITURA (doGet) =====================
function doGet(e) {
  try {
    var p = (e && e.parameter) ? e.parameter : {};
    var acao = String(p.acao || '');
    var chave = String(p.chave || '');

    if (chave !== CHAVE_SECRETA) {
      return json_({ ok: false, mensagem: 'Chave secreta incorreta. Confira CHAVE_SECRETA (aqui) e APPS_CHAVE_SECRETA (no app.js) — as duas precisam ser iguais.' });
    }

    if (acao === 'ping') {
      var info = lerBanco_();
      // Mostra QUAL planilha está sendo usada — se você "não acha" os dados na
      // aba DADOS, é bem possível que exista mais de uma planilha no Drive e
      // você esteja abrindo a errada.
      var planilhaUrl = '';
      try { planilhaUrl = SpreadsheetApp.openById(obterOuCriarBanco_()).getUrl(); }
      catch (e2) { planilhaUrl = 'não foi possível ler: ' + e2.message; }
      return json_({
        ok: true,
        pong: true,
        script: SCRIPT_VERSAO,
        projeto: 'sistema-notas-turmas',
        versao: info.versao,
        temDados: !!info.dados,
        planilha: planilhaUrl,
        atualizadoEm: info.atualizadoEm,
        backupSemanalAtivo: temDisparador_(),
        mensagem: 'Conexão OK com o Apps Script.'
      });
    }

    if (acao === 'carregar') {
      var atual = lerBanco_();
      // ok:true + dados:null = "nuvem ainda vazia" (o app mostra "Nenhum dado na nuvem ainda.")
      return json_({ ok: true, script: SCRIPT_VERSAO, dados: atual.dados || null, versao: atual.versao });
    }

    return json_({ ok: false, mensagem: 'Ação desconhecida: ' + acao });
  } catch (err) {
    return json_({ ok: false, mensagem: 'Erro ao ler os dados: ' + err.message });
  }
}

// ===================== GRAVAÇÃO (doPost) =====================
function doPost(e) {
  // LockService: garante que 2 pessoas salvando no MESMO segundo não corrompam
  // o banco (um espera o outro terminar).
  var lock = LockService.getScriptLock();
  try {
    lock.waitLock(20000); // espera até 20 s
  } catch (erro) {
    return json_({ ok: false, mensagem: 'Servidor ocupado (outro salvamento em andamento). Tente de novo em instantes.' });
  }

  try {
    var corpo = {};
    try {
      corpo = JSON.parse(e.postData.contents);
    } catch (erro) {
      return json_({ ok: false, mensagem: 'Corpo da requisição não é um JSON válido.' });
    }

    var chave = String(corpo.chave || (e.parameter ? e.parameter.chave : '') || '');
    if (chave !== CHAVE_SECRETA) {
      return json_({ ok: false, mensagem: 'Chave secreta incorreta. Confira CHAVE_SECRETA (aqui) e APPS_CHAVE_SECRETA (no app.js).' });
    }
    if (corpo.acao !== 'salvar') {
      return json_({ ok: false, mensagem: 'Ação desconhecida: ' + corpo.acao });
    }

    var info = lerBanco_();
    var versaoCliente = Number(corpo.versao || 0);
    if (!isFinite(versaoCliente)) versaoCliente = 0;
    var versaoServidor = info.versao;
    var dadosServidor = info.dados || { turmas: {} };

    // "forcar" vem só da RESTAURAÇÃO DE BACKUP (o usuário confirmou no diálogo
    // que quer substituir a nuvem inteira) — nesse caso a versão é ignorada.
    var forcar = (corpo.forcar === true);

    // ---- CONFLITO: outro usuário gravou depois que este navegador leu ----
    if (!forcar && versaoCliente !== versaoServidor) {
      return json_({
        conflito: true,
        script: SCRIPT_VERSAO,
        versao: versaoServidor,
        dados: dadosServidor,
        mensagem: 'Os dados da nuvem estão mais novos que a sua cópia local.'
      });
    }

    var novosDados = null;
    var operacoes = (corpo.operacoes && Object.prototype.toString.call(corpo.operacoes) === '[object Array]')
      ? corpo.operacoes : null;

    if (operacoes) {
      // Incremental: só o que o usuário digitou (protege notas de colegas)
      novosDados = JSON.parse(JSON.stringify(dadosServidor));
      aplicarOperacoes_(novosDados, operacoes);
    } else if (corpo.dados && typeof corpo.dados === 'object') {
      // Completo: restauração de backup (forcar) ou 1º sincronismo
      novosDados = JSON.parse(JSON.stringify(corpo.dados));
      if (!novosDados.turmas || typeof novosDados.turmas !== 'object') novosDados.turmas = {};
    } else {
      return json_({ ok: false, mensagem: 'Requisição sem "dados" e sem "operacoes".' });
    }

    var novaVersao = versaoServidor + 1;
    gravarBanco_(novaVersao, novosDados);

    return json_({ ok: true, script: SCRIPT_VERSAO, versao: novaVersao, gravadoEm: new Date().toISOString() });
  } catch (err) {
    return json_({ ok: false, mensagem: 'Erro ao salvar: ' + err.message });
  } finally {
    lock.releaseLock();
  }
}

// Aplica no servidor as mesmas operações que o app.js aplica no navegador:
//   op célula = { op:'nota'|'conceito'|'frequencia'|'situacao', turmaId,
//                 disciplinaId, alunoId, bimestre, valor }
//   remendo   = { op:'caminho', caminho:['turmas', id, 'nome'], valor } (define)
//                                            ou { ..., remover:true }  (apaga)
// Os remendos vêm de um diff contra o último estado que este cliente confirmou:
// como só mexem no que mudou, dá para MESCLAR com o que outro usuário salvou
// (as turmas criadas pelo colega não são tocadas) em vez de dar conflito.
function aplicarOperacoes_(dados, operacoes) {
  if (!dados.turmas || typeof dados.turmas !== 'object') dados.turmas = {};

  for (var i = 0; i < operacoes.length; i++) {
    var op = operacoes[i];
    if (!op || !op.op) continue;

    if (op.op === 'caminho') {
      definirCaminho_(dados, op.caminho, op.valor, op.remover === true);
      continue;
    }

    if (!op.turmaId) continue;
    var turma = dados.turmas[op.turmaId];
    if (!turma) continue; // turma apagada por outra pessoa: ignora em vez de quebrar

    if (!turma.notas) turma.notas = {};
    if (!turma.frequencias) turma.frequencias = {};
    var vazio = (op.valor === null || op.valor === undefined || op.valor === '');

    if (op.op === 'nota') {
      var b = op.bimestre;
      if (!turma.notas[b]) turma.notas[b] = {};
      if (!turma.notas[b][op.disciplinaId]) turma.notas[b][op.disciplinaId] = {};
      if (vazio) delete turma.notas[b][op.disciplinaId][op.alunoId];
      else turma.notas[b][op.disciplinaId][op.alunoId] = Number(op.valor);

    } else if (op.op === 'conceito') {
      if (!turma.conceitosFinais) turma.conceitosFinais = {};
      if (!turma.conceitosFinais[op.alunoId]) turma.conceitosFinais[op.alunoId] = {};
      if (vazio) delete turma.conceitosFinais[op.alunoId][op.disciplinaId];
      else turma.conceitosFinais[op.alunoId][op.disciplinaId] = Number(op.valor);

    } else if (op.op === 'frequencia') {
      if (!turma.frequencias[op.bimestre]) turma.frequencias[op.bimestre] = {};
      if (vazio) delete turma.frequencias[op.bimestre][op.alunoId];
      else turma.frequencias[op.bimestre][op.alunoId] = Number(op.valor);

    } else if (op.op === 'situacao') {
      if (!turma.situacoesFinais) turma.situacoesFinais = {};
      if (!turma.situacoesFinais[op.alunoId]) turma.situacoesFinais[op.alunoId] = {};
      if (vazio) delete turma.situacoesFinais[op.alunoId][op.disciplinaId];
      else turma.situacoesFinais[op.alunoId][op.disciplinaId] = String(op.valor);
    }
  }
}

// Define ou apaga um caminho completo dentro do objeto de dados.
// Percorre criando os objetos que faltam; NÃO entra dentro de arrays
// (no diff do app.js, arrays — alunos/disciplinas — são trocados inteiros).
function definirCaminho_(obj, caminho, valor, remover) {
  if (!obj || typeof obj !== 'object' || !caminho ||
      Object.prototype.toString.call(caminho) !== '[object Array]' || !caminho.length) return false;
  var alvo = obj;
  for (var i = 0; i < caminho.length - 1; i++) {
    var k = String(caminho[i]);
    if (alvo === null || typeof alvo !== 'object' || Array.isArray(alvo)) return false;
    if (alvo[k] === null || typeof alvo[k] !== 'object' || Array.isArray(alvo[k])) {
      if (remover) return false; // não existe o que atravessar
      alvo[k] = {};
    }
    alvo = alvo[k];
  }
  var ultimo = String(caminho[caminho.length - 1]);
  if (remover) {
    if (alvo && typeof alvo === 'object' && !Array.isArray(alvo)) delete alvo[ultimo];
  } else {
    alvo[ultimo] = valor;
  }
  return true;
}

// ===================== PLANILHA (banco de dados) =====================
function obterOuCriarBanco_() {
  var id = PropertiesService.getScriptProperties().getProperty(PROP_SS);
  if (id) {
    try {
      SpreadsheetApp.openById(id); // confere se ainda existe
      return id;
    } catch (e) {
      PropertiesService.getScriptProperties().deleteProperty(PROP_SS); // apagada: recria
    }
  }
  var novo = SpreadsheetApp.create(NOME_BANCO);
  PropertiesService.getScriptProperties().setProperty(PROP_SS, novo.getId());
  var sh = novo.getSheets()[0];
  sh.setName(ABA_DADOS);
  Logger.log('Planilha criada: ' + novo.getUrl());
  return novo.getId();
}

function lerBanco_() {
  var id = obterOuCriarBanco_();
  var sh = SpreadsheetApp.openById(id).getSheetByName(ABA_DADOS);
  if (!sh) return { versao: 0, dados: null, atualizadoEm: null };

  var versao = Number(sh.getRange(1, 2).getValue());
  if (!isFinite(versao)) versao = 0;
  var atualizadoEm = sh.getRange(2, 2).getValue();
  var fragmentos = Number(sh.getRange(3, 2).getValue());
  if (!isFinite(fragmentos) || fragmentos <= 0) {
    return { versao: versao, dados: null, atualizadoEm: atualizadoEm };
  }

  var bruto = sh.getRange(5, 2, fragmentos, 1).getDisplayValues();
  var texto = '';
  for (var i = 0; i < bruto.length; i++) texto += String(bruto[i][0] === null ? '' : bruto[i][0]);

  if (!texto) return { versao: versao, dados: null, atualizadoEm: atualizadoEm };

  try {
    return { versao: versao, dados: JSON.parse(texto), atualizadoEm: atualizadoEm };
  } catch (e) {
    throw new Error('O banco de dados está corrompido (JSON inválido na planilha). Restaure um backup .json pela aba do administrador.');
  }
}

function gravarBanco_(versao, dados) {
  var id = obterOuCriarBanco_();
  var ss = SpreadsheetApp.openById(id);
  var sh = ss.getSheetByName(ABA_DADOS) || ss.insertSheet(ABA_DADOS);

  var json = JSON.stringify(dados);
  var fragmentos = [];
  for (var i = 0; i < json.length; i += TAM_FRAGMENTO) {
    fragmentos.push(json.substring(i, i + TAM_FRAGMENTO));
  }

  var linhas = [];
  linhas.push(['versao', versao]);
  linhas.push(['atualizadoEm', new Date().toISOString()]);
  linhas.push(['fragmentos', fragmentos.length]);
  linhas.push(['indice', 'fragmento']);       // cabeçalho (linha 4)
  for (var j = 0; j < fragmentos.length; j++) linhas.push([j + 1, fragmentos[j]]);

  sh.clear(); // remove conteúdo e formatação antigas (evita "linhas fantasma")
  sh.getRange(1, 1, linhas.length, 2).setValues(linhas);
  sh.getRange(5, 2, Math.max(fragmentos.length, 1), 1).setNumberFormat('@'); // texto puro
  sh.getRange(1, 4).setValue('NÃO EDITE ESTA ABA. Os fragmentos do JSON começam na linha 5, coluna B. Apague só a planilha inteira se quiser zerar o banco.');
}

// ===================== BACKUP SEMANAL NO GOOGLE DRIVE =====================
// Roda sozinha (disparador de 7 em 7 dias) ou manualmente pela lista de funções.
// Gera: Backups - Sistema de Notas (JSON)/backup-notas-AAAA-MM-DD.json
function backupSemanalNoDrive() {
  var lock = LockService.getScriptLock();
  try {
    lock.waitLock(20000);
  } catch (e) {
    Logger.log('Backup pulado: banco ocupado.');
    return 'Backup pulado: banco ocupado no momento.';
  }

  try {
    var info = lerBanco_();
    if (!info.dados) {
      Logger.log('Backup semanal: ainda não há dados na nuvem, nada foi gerado.');
      return 'Ainda não há dados na nuvem — nenhum backup foi gerado.';
    }

    var pasta = obterOuCriarPasta_();

    // Mesmo envelope do botão "Baixar backup (.json)" do app → dá pra restaurar direto
    var conteudo = JSON.stringify({
      aplicativo: 'sistema-notas-turmas',
      tipo: 'backup',
      versao: 1,
      geradoEm: new Date().toISOString(),
      origem: 'backup automático semanal — Google Apps Script (Google Drive)',
      dados: info.dados
    }, null, 2);

    var hoje = new Date().toISOString().slice(0, 10);           // AAAA-MM-DD
    var nome = 'backup-notas-' + hoje + '.json';

    // Se já existe arquivo com esse nome hoje (teste manual repetido), apaga e recria
    var existentes = pasta.getFilesByName(nome);
    while (existentes.hasNext()) existentes.next().setTrashed(true);

    var arquivo = pasta.createFile(nome, conteudo);
    var apagados = limparBackupsAntigos_(pasta);
    var total = contarBackups_(pasta);

    Logger.log('Backup gerado: ' + arquivo.getName() + ' | ' + arquivo.getUrl());
    return 'OK: ' + arquivo.getName() + ' → ' + arquivo.getUrl() +
           ' (total na pasta: ' + total + ', apagados por excesso: ' + apagados + ')';
  } finally {
    lock.releaseLock();
  }
}

function obterOuCriarPasta_() {
  var props = PropertiesService.getScriptProperties();
  var id = props.getProperty(PROP_PASTA);
  if (id) {
    try {
      var pasta = DriveApp.getFolderById(id);
      return pasta;
    } catch (e) {
      props.deleteProperty(PROP_PASTA);
    }
  }
  // Procura pela pasta já existente (evita duplicar se você rodar setup 2 vezes)
  var achadas = DriveApp.getFoldersByName(NOME_PASTA_BACKUP);
  if (achadas.hasNext()) {
    var p = achadas.next();
    props.setProperty(PROP_PASTA, p.getId());
    return p;
  }
  var nova = DriveApp.createFolder(NOME_PASTA_BACKUP);
  props.setProperty(PROP_PASTA, nova.getId());
  Logger.log('Pasta de backups criada: ' + nova.getUrl());
  return nova;
}

function contarBackups_(pasta) {
  var n = 0;
  var it = pasta.getFiles();
  while (it.hasNext()) {
    if (/^backup-notas-.*\.json$/i.test(it.next().getName())) n++;
  }
  return n;
}

// Mantém apenas os MAX_BACKUPS mais recentes (nomes com data AAAA-MM-DD
// já saem em ordem cronológica se ordenados de trás pra frente).
function limparBackupsAntigos_(pasta) {
  var lista = [];
  var it = pasta.getFiles();
  while (it.hasNext()) {
    var f = it.next();
    if (/^backup-notas-.*\.json$/i.test(f.getName())) lista.push(f);
  }
  lista.sort(function (a, b) { return b.getName().localeCompare(a.getName()); });
  var apagados = 0;
  for (var i = MAX_BACKUPS; i < lista.length; i++) {
    lista[i].setTrashed(true);
    apagados++;
  }
  return apagados;
}

// ===================== INSTALAÇÃO / DISPARADOR SEMANAL =====================
// Rode UMA vez (função "setup") → autoriza e cria tudo.
// É seguro rodar de novo: só cria o que falta e NÃO duplica nada.
// Cada passo é isolado em try/catch, para que um erro não derrube os próximos
// (o motivo do setup antigo parar no meio).
function setup() {
  var erros = [];

  // Passo 1: planilha de dados (aba "DADOS")
  try {
    var id = obterOuCriarBanco_();
    Logger.log('1) Planilha de dados: ' + SpreadsheetApp.openById(id).getUrl());
  } catch (e) {
    erros.push('1) Planilha: ' + e.message);
  }

  // Passo 2: pasta de backups no Drive
  try {
    var pasta = obterOuCriarPasta_();
    Logger.log('2) Pasta de backups semanais: ' + pasta.getUrl());
  } catch (e) {
    erros.push('2) Pasta no Drive: ' + e.message);
  }

  // Passo 3: disparador semanal (7 em 7 dias)
  try {
    Logger.log('3) ' + criarDisparadorSemanal());
  } catch (e) {
    erros.push('3) Disparador semanal: ' + e.message);
  }

  // Passo 4: 1º backup imediato, para você já conferir a pasta do Drive
  try {
    Logger.log('4) ' + backupSemanalNoDrive());
  } catch (e) {
    erros.push('4) Backup: ' + e.message);
  }

  if (erros.length) {
    Logger.log('==== SETUP COM ERROS ====\n- ' + erros.join('\n- '));
    Logger.log('Rode a função diagnosticoBackup() — ela mostra passo a passo onde quebra.');
    return 'Setup com erro(s): ' + erros.join(' | ');
  }
  Logger.log('==== SETUP CONCLUÍDO SEM ERROS ====');
  return 'Setup concluído sem erros.';
}

// Diagnóstico: rode quando qualquer coisa falhar. Ela testa cada passo
// isoladamente e escreve no Registro/Executions ✅ o que deu certo e
// ❌ + a mensagem exata do que deu errado.
function diagnosticoBackup() {
  var ok = true;

  function passo(nome, fn) {
    try {
      var r = fn();
      Logger.log('✅ ' + nome + (r ? (' → ' + r) : ''));
    } catch (e) {
      ok = false;
      Logger.log('❌ ' + nome + ' → ERRO: ' + e.message);
    }
  }

  passo('Planilha de dados', function () {
    var ssid = obterOuCriarBanco_();
    return SpreadsheetApp.openById(ssid).getUrl();
  });

  passo('Ler dados da nuvem', function () {
    var info = lerBanco_();
    return 'versão ' + info.versao + ' | tem dados: ' + (info.dados ? 'SIM' : 'NÃO');
  });

  passo('Pasta de backups no Drive', function () {
    return obterOuCriarPasta_().getUrl();
  });

  passo('Gerar o backup (.json)', function () {
    return backupSemanalNoDrive();
  });

  passo('Disparador semanal', function () {
    return temDisparador_() ? 'EXISTE — não precisa criar de novo' : ('AUSENTE → ' + criarDisparadorSemanal());
  });

  Logger.log(ok ? '==== TUDO OK ====' : '==== HÁ ERROS: veja as linhas ❌ acima ====');
  return ok ? 'Tudo OK — veja o Registro.' : 'Há erros — veja as linhas ❌ no Registro.';
}

// Cria o disparador: a cada 7 dias, às HORA_BACKUP (padrão 06:00).
// Pode ser rodada quantas vezes quiser: nunca duplica o disparador.
//
// ⚠️ O Google NÃO possui atMinute() — o método oficial é nearMinute()
//    (a disparada acontece ±15 min do minuto informado). Esse era o motivo
//    do erro "Cannot find function atMinute" ao rodar o setup().
function criarDisparadorSemanal() {
  var existentes = ScriptApp.getProjectTriggers();
  for (var i = 0; i < existentes.length; i++) {
    if (existentes[i].getHandlerFunction() === 'backupSemanalNoDrive') {
      return 'Disparador semanal já estava criado (nada foi duplicado).';
    }
  }

  // 1ª tentativa: toda SEGUNDA, ~06:00 (fuso do script)
  try {
    ScriptApp.newTrigger('backupSemanalNoDrive')
      .timeBased()
      .everyWeeks(1)                                // a cada 1 semana
      .onWeekDay(ScriptApp.WeekDay.MONDAY)          // dia fixo
      .atHour(HORA_BACKUP)                          // ~hora
      .nearMinute(0)                                // minuto (±15 min)
      .create();
    return 'Disparador semanal CRIADO: toda SEGUNDA, ~' + HORA_BACKUP + 'h00 (fuso do script).';
  } catch (e1) {
    Logger.log('Aviso: 1ª tentativa falhou (' + e1.message + ') — tentando sem dia fixo.');
  }

  // 2ª tentativa: a cada 7 dias, ~06:00 (mesmo dia da semana do dia da criação)
  try {
    ScriptApp.newTrigger('backupSemanalNoDrive')
      .timeBased()
      .everyWeeks(1)
      .atHour(HORA_BACKUP)
      .nearMinute(0)
      .create();
    return 'Disparador semanal CRIADO: a cada 7 dias, ~' + HORA_BACKUP + 'h00 (fuso do script).';
  } catch (e2) {
    Logger.log('Aviso: 2ª tentativa falhou (' + e2.message + ') — criando no mínimo a frequência semanal.');
  }

  // 3ª tentativa: mínimo absoluto — a cada 7 dias, horário aleatório
  ScriptApp.newTrigger('backupSemanalNoDrive').timeBased().everyWeeks(1).create();
  return 'Disparador semanal CRIADO (modo mínimo): a cada 7 dias, em horário aleatório.';
}

function removerDisparadorSemanal() {
  var existentes = ScriptApp.getProjectTriggers();
  var n = 0;
  for (var i = 0; i < existentes.length; i++) {
    if (existentes[i].getHandlerFunction() === 'backupSemanalNoDrive') {
      ScriptApp.deleteTrigger(existentes[i]);
      n++;
    }
  }
  return n ? (n + ' disparador(es) apagado(s).') : 'Nenhum disparador encontrado.';
}

function temDisparador_() {
  var existentes = ScriptApp.getProjectTriggers();
  for (var i = 0; i < existentes.length; i++) {
    if (existentes[i].getHandlerFunction() === 'backupSemanalNoDrive') return true;
  }
  return false;
}

// Diagnóstico: rode para conferir se TUDO está de pé.
function statusDoSistema() {
  var info;
  try { info = lerBanco_(); } catch (e) { info = { erro: e.message }; }
  Logger.log('Planilha...: ' + (PropertiesService.getScriptProperties().getProperty(PROP_SS) || 'não criada'));
  Logger.log('Pasta......: ' + (PropertiesService.getScriptProperties().getProperty(PROP_PASTA) || 'não criada'));
  Logger.log('Versão.....: ' + (info.versao !== undefined ? info.versao : info.erro));
  Logger.log('Tem dados..: ' + (info.dados ? 'sim (' + Object.keys(info.dados.turmas || {}).length + ' turmas)' : 'não'));
  Logger.log('Disparador.: ' + (temDisparador_() ? 'semanal ATIVO' : 'DESLIGADO — rode criarDisparadorSemanal()'));
  return 'Veja o registro ao lado (Registro / Executions).';
}

PARTE 5 — BACKUP SEMANAL AUTOMÁTICO NO GOOGLE DRIVE (o que você pediu)
================================================================================
O que foi implementado:
  • Disparador (trigger) instalável:  a cada 7 dias, às 06:00  roda
    backupSemanalNoDrive().
  • Ele lê o JSON completo do banco e GRAVA na pasta do Drive
        "Backups - Sistema de Notas (JSON)"
    um arquivo:
        backup-notas-2026-10-20.json      (data = dia da execução)
  • O arquivo guarda os últimos 12 backups (≈ 3 meses); os mais velhos vão para
    a lixeira do Drive automaticamente.
  • Rodar de novo no mesmo MESMO dia substitui o arquivo do dia (não acumula lixo).
  • O formato é idêntico ao do botão "Baixar backup (.json)" do site → pode ser
    restaurado pela aba Admin → 💾 Backup e Restauração → Restaurar backup (.json).

Já está ligado?
  • O setup() cria o disparador sozinho. Para conferir, rode a função
    "statusDoSistema" → Disparador.: semanal ATIVO.
  • Ou veja no editor: painel esquerdo  ⏰ Acionadores (Triggers) → deve aparecer
    "backupSemanalNoDrive | Depois de 7 dias (06h00)".

Criar manualmente / religar:
  • No editor, selecione a função  criarDisparadorSemanal  → ▶ Executar.
    (É idempotente: se já existir, não duplica.)
  • Semana errada, hora errada? Edite HORA_BACKUP no topo do script e, se quiser
    outro dia da semana, troque .everyWeeks(1) por uma versão com
    .onDayOfWeek(...) — ou simplesmente mantenha: a cada 7 dias é exatamente o
    que foi pedido.

Testar AGORA sem esperar a semana:
  • Selecione a função  backupSemanalNoDrive  → ▶ Executar.
  • Ou rode  setup()  (ele cria o que falta e já gera o 1º backup).
  • Depois abra o Drive → pasta "Backups - Sistema de Notas (JSON)" → baixe o
    .json e veja se tem "dados" → "turmas" lá dentro.

Receber no e-mail também? (opcional, 5 linhas)
  No mesmo script, crie uma função e ligue um disparador semanal nela:
    function backupPorE-mail() {

                 .getProperty(PROP_PASTA)).getFilesByName('backup-notas-' +

Desligar o backup semanal:
  • Função  removerDisparadorSemanal  → ▶ Executar.
  • Ou no painel ⏰ Acionadores → lixeira ao lado do acionador.
  • A pasta do Drive e os arquivos já gerados continuam lá.

PARTE 8 — LIMITES / COTAS DO GOOGLE (são folgados para este app)
================================================================================
• 6 minutos por execução            → cada salvamento leva < 1 s.
• Gatilhos (disparadores): até 20 por conta e ~90 min/dia de execução.
  Usamos 1, rodando 1x por semana por segundos.
• Drive: milhares de arquivos criados por dia → geramos 1/semana.
• Planilha: ~50 operações de leitura/escrita por minuto. Cada salvamento faz
  1 leitura + 1 escrita; o app já agrupa alterações (debounce de 400 ms) e só
  manda a célula alterada.
• Célula: 50.000 caracteres → usamos fatias de 40.000. Mesmo com MUITOS alunos,
  cabem centenas de megabytes de JSON antes de qualquer limite prático.
• Execuções simultâneas: o LockService serializa (um espera o outro, sem erro).
• Se a conta for Google Workspace de escola, o administrador pode bloquear
  scripts de terceiros/disparadores → nesse caso publique com uma conta pessoal
  (@gmail.com).

PARTE 9 — SOLUÇÃO DE PROBLEMAS
================================================================================
Dica universal: rode a função  diagnosticoBackup() — ela executa cada passo
isoladamente e escreve no Registro/Executions ✅ o que funcionou e ❌ + a
mensagem exata do que falhou.

"TypeError: Cannot find function atMinute" (erro no setup/backup semanal)
  O Google não tem atMinute() — o método é  nearMinute()  (±15 min). Já está
  corrigido no código da PARTE 2 (criarDisparadorSemanal usa nearMinute e ainda
  tem 3 níveis de fallback). Coloque o código atualizado e rode setup() de novo.

"Falha na conexão" / "Failed to fetch"
  1. URL é a de APLICATIVO DA WEB e termina em /exec? (não /dev, não link do editor)
  2. Deploy → "Quem tem acesso" = Qualquer pessoa?
  3. Você salvou o código DEPOIS do deploy? Se sim, atualize a implantação
     (PARTE 6) — senão a URL antiga continua rodando o código antigo.
  4. Abra a URL /exec direto no navegador: tem que vir JSON. Se vier HTML de
     erro de autorização → refaça o deploy e autorize.
  5. Teste "Testar Conexão" de novo.

"Chave secreta incorreta"
  CHAVE_SECRETA (Código.gs) ≠ APPS_CHAVE_SECRETA (app.js). Iguale as duas.
  Trocou a chave? Atualize a implantação (PARTE 6).

Resposta "conflito: true"
  Não é erro fatal: outra pessoa salvou enquanto você editava. O app.js resolve
  sozinho — carrega a versão nova, reaplica por cima o que você digitou (notas,
  conceitos, frequências E alterações de estrutura como turmas/disciplinas/alunos)
  e reenvia automaticamente. Você só vê a mensagem de conflito de forma
  intermitente enquanto isso acontece; em seguida ela vira "✅ Salvo na nuvem".
  Se ela aparecer MUITAS vezes seguidas: duas pessoas (ou duas abas) estão
  salvando ao mesmo tempo — o app para de tentar e mantém suas alterações
  pendentes; faça uma nova edição qualquer para reenviar.

O site mostra "O Apps Script da nuvem está DESATUALIZADO"
  O app.js confere o número "script" devolvido pelo backend (precisa ser 2).
  Atualize o Código.gs com o código da PARTE 2 e publique NOVA VERSÃO:
  DEPLOY → Gerenciar implantações → ✏ → Versão: + Nova versão → IMPLANTAR
  (mesma URL). Enquanto isso, turmas/disciplinas/alunos NÃO são gravados.

"Erro ao salvar: O banco de dados está corrompido"
  Restaure um backup .json pela aba do administrador, ou apague a aba DADOS e
  rode statusDoSistema.

O backup semanal NÃO apareceu no Drive
  • ⏰ Acionadores existe com backupSemanalNoDrive? Se não → criarDisparadorSemanal().
  • Rode statusDoSistema: "Disparador.: semanal ATIVO"?
  • Veja o erro: editor → painel  🔎 Executions/Registro → clique na execução
    vermelha para ver a mensagem.
  • Se a conta tiver 2 etapas, o Google às vezes pede revalidação de gatilhos:
    acione o ⚠ do painel Acionadores → revisar/permissão.
  • Timezone do script ≠ America/Sao_Paulo → troque nas Configurações do projeto.

"Pasta criada em outro lugar"
  A pasta nasce na raiz do Drive de quem executou o setup. Mova para onde quiser
  (o script guarda o ID e continua achando). Não renomeie nem apague: se apagar,
  rode setup() de novo que ele cria outra.

Dica final
  Deixe aberto na aba do editor:  ⏰ Acionadores  e  🔎 Executions. É ali que
  você vê o backup semanal rodando de verdade, semana após semana.
