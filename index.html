☁️ Backup na Nuvem (Google Sheets / Apps Script)

Como funciona: opcional. Se quiser que os dados fiquem salvos online (para usar de qualquer computador pelo Railway), crie um Google Apps Script, faça o deploy e cole aqui a URL de implantação (que termina em /exec). Enquanto não preencher a URL, o sistema continua usando o armazenamento local (localStorage) do navegador.

💾 Backup e Restauração

Como funciona: o backup é gerado direto da nuvem (Google Sheets / Apps Script), que é a única fonte de dados do sistema — nada é gravado no navegador. Use Baixar backup para salvar um arquivo .json de segurança em seu computador, e Restaurar backup para recarregar esse arquivo em caso de problema.
Atenção: a restauração substitui todos os dados da nuvem pelos do arquivo.

👥 Relatório por Turma

Boletim Final: tabela com as notas de cada bimestre, o 5º Conceito (média aritmética dos 4 bimestres), a frequência média (%) e a Situação Final de cada aluno por disciplina. O administrador pode editar o 5º Conceito; o professor visualiza tudo e escolhe a Situação Final (Aprovado por nota e frequência, Aprovado pelo conselho, Reprovado por nota ou Reprovado por frequência) — decisão manual, sem cálculo automático.
Conceito Final: a tab abaixo calcula automaticamente o 5º Conceito, fazendo a média aritmética das notas dos bimestres 1, 2, 3 e 4 para cada aluno de cada disciplina da turma selecionada.
Frequência por Bimestre: o administrador lança a frequência geral (%) de cada aluno em cada bimestre (0 a 100). Professores visualizam as frequências junto com as notas. Critério: > 75% = OK, = 75% = Limite, < 75% = Atenção.
